# スクリプト

`scripts/` ディレクトリには、ローカルワークフローや運用タスク用のヘルパースクリプトが含まれています。
タスクが明確にスクリプトに関連している場合に使用してください。それ以外の場合は CLI を優先してください。

## 規約

- スクリプトは、ドキュメントやリリースチェックリストで参照されていない限り、**任意** です。
- CLI サーフェスが存在する場合はそちらを優先してください（例：認証監視は `openclaw models status --check` を使用）。
- スクリプトはホスト固有であると想定してください。新しいマシンで実行する前に内容を確認してください。

## スクリプトを追加する場合

- スクリプトは集中的かつドキュメント化された状態を保ってください。
- 関連するドキュメントに短いエントリを追加してください（存在しない場合は作成してください）。
